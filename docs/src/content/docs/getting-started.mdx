<Aside type="caution">
  This theme requires **Tailwind CSS** to be installed and configured in your project for components to render correctly.
</Aside>

## Prerequisites

1.  You will need to have a Starlight website set up.
    If you don't have one yet, you can follow the ["Getting Started"](https://starlight.astro.build/getting-started) guide in the Starlight docs to create one.

2.  **Tailwind CSS** must be installed and configured in your project. If you haven't added it yet, run:
    ```sh
    npx astro add tailwind
    ```

## Installation

import { Steps, Tabs, TabItem } from "@astrojs/starlight/components";

<Steps>

1. `starlight-fumadocs` is a Starlight [plugin](https://starlight.astro.build/reference/plugins/). Install it by running the following command in your terminal:

   <Tabs syncKey="pkg">

   <TabItem label="npm">

   ```sh
   npm install starlight-fumadocs
   ```

   </TabItem>

   <TabItem label="pnpm">

   ```sh
   pnpm add starlight-fumadocs
   ```

   </TabItem>

   <TabItem label="Yarn">

   ```sh
   yarn add starlight-fumadocs
   ```

   </TabItem>

   </Tabs>

2. Configure the plugin in your Starlight [configuration](https://starlight.astro.build/reference/configuration/#plugins) in the `astro.config.mjs` file.

   ```diff lang="js"
   // astro.config.mjs
   import starlight from '@astrojs/starlight'
   import { defineConfig } from 'astro/config'
   +import starlightFumadocs from 'starlight-fumadocs'

   export default defineConfig({
     integrations: [
       starlight({
   +      plugins: [starlightFumadocs()],
         title: 'My Docs',
       }),
     ],
   })
   ```

3. [Start the development server](https://starlight.astro.build/getting-started/#start-the-development-server) to preview the theme in action.

</Steps>
