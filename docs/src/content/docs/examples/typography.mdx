## Paragraphs & Body Text

FumaDocs uses a clean 16px base with a 1.625 line-height. This paragraph contains **bold text using `strong`**, *italic text using `em`*, and a combination of ***bold and italic***. The font is Geist Sans, falling back to Inter, then system-ui.

A second paragraph follows with a [link to the getting started guide](/getting-started/) that has a subtle underline decoration using `text-decoration-color`. Hover over the link to see the opacity transition.

## Strong and Em

- **Bold / strong text** — should be visually heavier, same color as body text.
- *Italic / em text* — should be slanted, same color as body text.
- ***Bold italic*** — combined emphasis.
- `inline code` — monospace, bordered, subtle background.
